# Customize controls

Play with a keyboard and mouse or trackpad, or with touch on iPhone and iPad. Game controllers are not supported.

Open **Settings → Controls** from the title screen or the City menu. The Explore menu also has a **Control settings** button.

On iPad and Android, the Keyboard section appears when a hardware keyboard is attached. An on-screen keyboard does not reveal it. Attaching or disconnecting a keyboard updates the open Settings window; disconnecting cancels pending key entry. Desktop keeps keyboard settings available.

Choose **Build**, **Explore** or **General**, then select an action's primary or alternate key and press its replacement. Changes apply and save immediately for this player, independently of city saves. Menu captions, tooltips and interaction prompts follow the assigned keys.

- **Escape** cancels key entry. Escape, Tab, Enter and application modifier keys remain reserved for menus.
- **Backspace** clears an alternate key while editing that alternate.
- A conflict message keeps the previous assignment. Build and Explore can share keys; actions used together cannot. Walking Jump and vehicle Brake can share a key.
- **Restore default bindings** restores all keyboard assignments.

**Look sensitivity**, **Invert vertical look** and the short touch/mouse guide remain available without a hardware keyboard. Explore uses **Menu / Resume** to pause and resume movement. Help → **Playing the Game…** has the full gameplay guide.
