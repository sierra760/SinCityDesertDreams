# Station finish bitmap

`warm-terrazzo.png` is a deterministic 256² fleck image sampled by
`game/scripts/exploration/transit/stairwell_finish.gdshader` for the station
terrazzo finish. It was generated procedurally (seeded random flecks) for
Sin City: Desert Dreams and is the only bitmap the station finishes use.
Station furnishings are built at runtime by the shared finish system in
`game/scripts/exploration/transit/explore_station_interior.gd`.
